## Notes
- `plugins/` contains the local Bootstrap, jQuery, Font Awesome, EmojiOneArea, and Popper files used by the project.
- `styles/` contains the project's custom CSS files.
- `profile/` contains the default and deleted-user profile images.
- `images/` contains the preview images used by the project.
- `uploads/` is used for uploaded files/profile pictures.
- `chat_app_db.sql` is the database export.
